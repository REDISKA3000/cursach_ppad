# Project Rules

- Build a local MVP only.
- Use Python + FastAPI + Jinja2 + SQLite.
- Do not use React, Next.js, Docker, or complex auth.
- Prefer simple server-rendered pages.
- The system must work without an API key in mock mode.
- Never invent candidate facts.
- If data is missing, ask clarifying questions or add warnings.
- Keep code modular, readable, and easy to demo.
- Prioritize end-to-end working flow over sophistication.
